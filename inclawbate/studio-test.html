Studio API Test

Test the Inclawbate Studio endpoints. These power all AI creative tools in the ecosystem.

🎨 Image Generation
POST /api/inclawbate/ai/image
✂ Background Removal
POST /api/inclawbate/ai/remove-bg
📎 Drop an image or click to upload
🎤 Audio Transcription
POST /api/inclawbate/ai/transcribe
🎵 Drop audio or click to upload (mp3, wav, m4a)
📝 How apps use this
Any Inclawbate app can call these
// Generate an image in your app const res = await fetch('/api/inclawbate/ai/image', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ prompt: 'a friendly lobster', aspectRatio: '1:1' }) }); const { image } = await res.json(); // image = "data:image/png;base64,..." // Remove background const res2 = await fetch('/api/inclawbate/ai/remove-bg', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ image: base64ImageData, background: 'transparent' }) }); // Transcribe audio const res3 = await fetch('/api/inclawbate/ai/transcribe', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ audio: base64AudioData }) });
