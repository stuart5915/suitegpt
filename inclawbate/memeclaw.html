System Flow
🔎
Meme Detection
Know Your Meme publishes a newly certified meme. The MemeClaw agent detects it and pulls the name, image, description, and origin lore.
Trigger: KYM certification
🚀
Token Launch
Inclawbator auto-deploys a token on Base via Clanker. Token name, symbol, and image all derived from the meme. LP created automatically.
Auto or manual launch
🛠
Site Generation
AI generates a landing page from the template with lore, token info, community vote, and volume milestones. Published to inclawbate.app/s/[slug].
Fires after token deploy
🦞
Staking Pool Created
A staking pool is deployed for the token. Holders can stake to earn CLAWS rewards. LP fees auto-fund the rewards pool.
Fires after site publish
📈
Volume Milestones Unlock
As 24h trading volume grows, new services unlock automatically: weekly updates ($500), dedicated X account ($1K), dev focus ($2K), full build-out ($5K), autonomous agent ($10K).
Checked via DexScreener API
⚡
Community Vote Executes
Token holders vote on what the meme becomes next. The winning idea gets built by the Inclawbator. The meme evolves from a token into a product.

System Mechanics
Revenue Loop
LP fees from every meme token flow back to the Inclawbate ecosystem. More memes = more LP = more revenue. Self-sustaining.
Token Launch
Clanker on Base. 0.5% creator fee on trades. Pre-allocated supply for staking rewards and ecosystem.
Volume Triggers
DexScreener 24h volume checked in real-time. Each tier unlocks more Inclawbate resources for the token.
Staking
Stake meme tokens, earn CLAWS. Rewards funded by LP fees. Same staking infra as all Inclawbate tokens.
