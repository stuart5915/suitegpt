Info Strict equality check in claim()

Slither flags reward == 0 as a "dangerous strict equality." This is an intentional early-return to skip zero-value claims — a gas optimization, not a vulnerability.

✓ Safe — Intentional pattern
Info block.timestamp comparisons

Slither flags timestamp usage for reward period tracking. This is inherent to the Synthetix StakingRewards model — every staking contract uses block.timestamp. Miners can manipulate by ~15 seconds, negligible for a 30-day reward period.

✓ Safe — Standard staking pattern
Info Uninitialized stakerCount

Aderyn flags stakerCount as uninitialized (H-1). Solidity uint256 defaults to 0, which is the correct initial value. It increments on first stake.

✓ Safe — False positive

Security Features

Pass Reentrancy Protection

All state-changing functions use ReentrancyGuardUpgradeable. State updates occur before external calls (CEI pattern).

Pass Token Separation

recoverToken() blocks both staking and reward tokens. Admin cannot drain user funds.

Pass SafeERC20

All token transfers use OpenZeppelin SafeERC20 for safe transfer handling.

Pass Pausable + Emergency Withdraw

Admin can pause new stakes. Users can always unstake and claim, even when paused. Emergency withdraw available as last resort.

Pass UUPS Upgradeable with Renounce

Admin can push fixes via UUPS proxy. renounceUpgradeability() permanently locks the contract — no more upgrades ever.
