How Agent Skills Work
1
Discover
Agent fetches the skill spec JSON to learn what's available and how to call it.
2
Call
Agent calls the data endpoint directly. No API keys needed. Public and open.
3
Act
Agent uses the data to report, recommend, or take action on behalf of its user.
