# publicgoods.tech — AI Agent News & Directory Initiative

## What It Is

An independent-looking news site and X account covering the AI agent ecosystem. Publishes daily content about AI agent projects, public goods, and ecosystem updates. Tags projects in posts to drive engagement. Becomes the go-to source for AI agent news.

**Think: baseposting but for AI agents.**

## Why It Exists

1. **Marketing for Inclawbate** — Inclawbator is featured naturally as a top AI agent project
2. **Revenue stream** — Projects pay to be featured/promoted (sponsored posts, featured directory listings)
3. **Audience building** — Grows a following of AI agent builders and enthusiasts who funnel into Inclawbate
4. **Credibility** — Being an independent news source is more trustworthy than self-promotion

## Revenue Streams

| Stream | How it works | Est. Revenue |
|--------|-------------|-------------|
| **Sponsored posts** | Projects pay to be featured in daily updates | $200-1000/post |
| **Featured directory listings** | Premium placement in the agent directory | $50-200/month |
| **Newsletter sponsorship** | Sponsored section in weekly newsletter | $100-500/week |
| **Blog ads** | Display ads on blog articles (once traffic grows) | Passive |
| **Affiliate/referral** | Link to agent platforms with referral codes | Passive |
