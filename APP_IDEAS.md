# Inclawbate App Store — 50 App Ideas

All apps: single HTML file, dark theme, Realtime SDK for multiplayer, published via `/api/publish-site`.
Creator: stuman | Built on Inclawbate

---

## SOCIAL & MULTIPLAYER (1-12)

1. **Campfire** — Group chat room with rooms/channels. Emoji reactions, typing indicators. Realtime.
2. **Whiteboard** — Shared drawing canvas. Everyone draws together in real time. Color picker, brush sizes.
3. **Poll Booth** — Create polls, vote live, see results animate in real time. Great for community decisions.
4. **Confessions** — Anonymous message board. Post anonymously, upvote/downvote. No accounts needed.
5. **Jukebox** — Shared music queue. Everyone submits YouTube links, votes on next track, plays in sync.
6. **Debate Arena** — Two sides argue a topic, audience votes in real time. Timer rounds.
7. **AMA Stage** — One person takes questions from the audience. Upvote questions to surface the best ones.
8. **Vibe Check** — Post your current mood/vibe with a color + emoji. See everyone's vibes on a live wall.
9. **Countdown** — Create shared countdowns for launches, events, drops. Everyone watches together.
10. **Shoutbox** — Fast-scrolling live chat. Simple, retro, IRC-style. No frills.
11. **Story Chain** — Collaborative story writing. Each person adds one sentence. See the story grow.
12. **Secret Santa** — Group gift exchange organizer. Randomized assignments, anonymous wishlists.

## CRYPTO & DEFI TOOLS (13-24)

13. **Token Radar** — Paste any Base token address, get price, liquidity, holders, chart. Quick lookup.
14. **Wallet X-Ray** — Paste a wallet address, see all holdings, recent txns, PnL estimate.
15. **Gas Tracker** — Live Base gas prices with alerts. Historical chart.
16. **Swap Calculator** — Input token pair + amount, show estimated output across DEXs. No swap execution, just info.
17. **Whale Watch** — Live feed of large transactions on Base. Filter by token or size.
18. **Portfolio Pie** — Connect wallet or paste address, see portfolio as a pie chart with allocations.
19. **CLAWS Dashboard** — All-in-one: CLAWS price, staking stats, your balance, recent transfers, burn tracker.
20. **LP Calculator** — Input token pair + amounts, calculate impermanent loss at different price points.
21. **Token Deployer Guide** — Step-by-step interactive guide to deploying a token on Base. Educational.
22. **NFT Gallery** — Paste wallet address, see all NFTs in a beautiful grid. Share your collection.
23. **Airdrop Tracker** — Checklist of upcoming Base airdrops with eligibility criteria and dates.
24. **Fee Analyzer** — Paste wallet, see how much you've spent on gas fees total. Lifetime stats.

## PRODUCTIVITY & UTILITIES (25-37)

25. **Notepad** — Simple scratchpad that saves to localStorage. Markdown support. Dark mode.
26. **Pomodoro** — 25/5 timer with session counter. Optional shared mode so teams focus together.
27. **Unit Converter** — Length, weight, temp, crypto units (wei/gwei/eth), time zones. All in one.
28. **Color Picker** — Pick colors, get hex/rgb/hsl. Generate palettes. Copy to clipboard.
29. **QR Generator** — Paste any text/URL, get a QR code. Download as PNG.
30. **Markdown Preview** — Write markdown on the left, see rendered HTML on the right. Export.
31. **JSON Formatter** — Paste ugly JSON, get pretty-printed + validated output. Tree view.
32. **Regex Tester** — Write regex, test against sample text, see matches highlighted.
33. **Password Generator** — Generate secure passwords with custom length/complexity. Copy button.
34. **Base64 Tool** — Encode/decode Base64. Supports text and file upload.
35. **Habit Tracker** — Daily habit grid (like GitHub contribution chart). Track streaks.
36. **Flashcards** — Create and study flashcard decks. Spaced repetition. Shareable decks via Realtime.
37. **Meeting Timer** — Shared timer for meetings/standups. Shows who's been talking longest.

## GAMES & FUN (38-50)

38. **Trivia Royale** — Multiplayer trivia. Questions appear, everyone answers, fastest correct wins points.
39. **Tic Tac Toe** — Classic, but multiplayer via Realtime. Matchmaking, win streaks.
40. **Rock Paper Scissors** — Best of 3 against a live opponent. Leaderboard.
41. **Snake** — Classic snake game. Compete for high scores on a shared leaderboard.
42. **Drawing Guess** — One person draws, others guess what it is. Like Pictionary. Realtime.
43. **Word Scramble** — Unscramble words fastest. Multiplayer race mode.
44. **Reaction Test** — Click when the screen turns green. Millisecond leaderboard.
45. **Memory Match** — Flip cards to find pairs. Timed. Compete for best time.
46. **Dice Roller** — Roll dice with physics animation. Shared rolls for tabletop gaming.
47. **Coin Flip** — Animated coin flip. Shared mode for group decisions. History log.
48. **Number Guess** — Guess the number 1-100. Hot/cold hints. Multiplayer race.
49. **Typing Race** — Type a passage as fast as you can. Live WPM race against others.
50. **Slot Machine** — Pull the lever, animated reels. Just for fun (no real money). Leaderboard for lucky streaks.
